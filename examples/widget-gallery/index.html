Widget gallery

A conduit URL is bound to one sheet tab permanently — one URL can't drive widgets that write different-shaped rows. Set up a separate conduit per tab below (each with the columns that widget writes) and paste each one's own ID in; a real embed skips this and just hardcodes its own conduit URL directly.

This page also applies its own --xyz-* theme — accent, radius, font, all of it — to every widget below at once, set in one place (see this page's own :root block), not hardcoded per widget. Each widget's own README shows its plain, unbranded default; this is what the same widgets look like once a host actually themes them.

Shared by the two forms below — both write the same name/email shape, so one conduit covers both.

A real <xyz-contact-form> element — name/ email/message by default, with a built-in qualified-lead preset. Writes name/email/message/ services/budget. See xyz-contact-form/README.md.
